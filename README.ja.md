# CueJump

IINA 用の字幕サイドバープラグインです。再生中、現在のファイルの字幕をすべて一覧表示し、任意の項目をクリックするとその字幕の開始位置へ再生位置を移動します。

![CueJump のサイドバー](docs/screenshot.png)

## 用途

IINA は再生中の 1 行しか表示しないため、前後の文脈を確認できず、すでに再生した箇所を探すことも困難です。CueJump はファイル全体の字幕をサイドバーに一覧表示し、検索と移動の機能を追加します。主な用途は次のとおりです。

- 内容は覚えているが時刻が分からない箇所へ戻る
- 順番に再生せず、特定の章や論点へ移動する
- 講義録画、インタビュー、会議の録画を復習する
- 語学学習で、IINA 本来の前後字幕移動と組み合わせて用いる

## 機能

| 機能 | 説明 |
|---|---|
| 字幕一覧 | ファイル内のすべての字幕をタイムコード付きで表示 |
| クリックで移動 | 項目をクリックすると、その字幕の開始時刻へ再生位置を移動 |
| 検索 | 入力に応じて絞り込み、一致箇所を強調表示。`Enter` で最初の一致へ移動 |
| 再生への追従 | 再生中の項目を強調し、一覧の中央に保つ。手動でスクロールすると 1.5 秒間追従を停止。無効化も可能 |
| 文字サイズ | 11〜16 px。一覧と字幕本文の両方に適用 |
| 背景 | ガラス（完全に透明）、つや消し（半透明）、不透明 |
| 表示言語 | システム設定に追従、または 中文 / English / 日本語 を指定 |

## インストール

1. 最新の `iina-cuejump-x.y.z.iinaplgz` をダウンロードします
2. ダブルクリックし、IINA の確認ダイアログで「インストール」を選択します
3. IINA を完全に終了してから再起動します（プラグインは起動時に読み込まれます）

`IINA → 設定 → プラグイン → GitHub からインストール` にリポジトリの URL を入力する方法でもインストールできます。

## 使い方

字幕のある動画を開き、サイドバーで **CueJump** タブを選択します。

| 操作 | 結果 |
|---|---|
| 一覧の項目をクリック | その字幕の開始時刻へ移動 |
| `⌘F` | 検索欄にフォーカスを移動 |
| キーワードを入力 | 絞り込みと一致箇所の強調表示をリアルタイムで実行 |
| `Enter` | 最初の一致へ移動 |
| `Esc` | 検索文字列を消去 |
| `Shift + ←` / `Shift + →` | IINA 本来の前後の字幕へ移動 |
| `↻` | 字幕ファイルを再読み込み（外部字幕を編集した後に使用） |

## 字幕ファイルの検索順序

次の順序で検索します。

1. 現在読み込まれている外部字幕トラック
2. 動画と同じフォルダにあり、同じベース名で拡張子が `.srt`、`.vtt`、`.ass`、`.ssa` のファイル

対応形式は SRT、WebVTT、ASS / SSA です。ASS および SSA の上書きコード（`{\b1}` など）は解析時に除去されます。

## 設定

`IINA → 設定 → プラグイン → CueJump` で以下を設定できます。

- **サイドバーの背景**：ガラス / つや消し / 不透明
- **文字サイズ**：11〜16 px
- **診断情報**：サイドバーにプラグイン内部のログを表示
- **言語**：システムに従う / English / 中文 / 日本語

サイドバーの `A−`、`A+`、背景ボタンも同じ設定を変更し、即座に反映されます。

## よくある質問

**サイドバーが空です**
字幕ファイルが見つかっていません。動画と同じ場所に同じベース名で `.srt`（または `.vtt` / `.ass`）ファイルがあるか確認するか、IINA で字幕トラックを手動で読み込み、`↻` を押してください。

**IINA 標準の字幕表示との違い**
IINA は常に 1 行のみを表示します。CueJump はすべての項目を一覧表示し、検索と移動を提供します。両者は同時に使用できます。

**字幕ファイルは変更されますか**
変更されません。プラグインは読み取りのみを行います。

**ネットワーク動画やライブ配信に対応していますか**
一覧はローカルの字幕ファイル、または読み込み済みの字幕トラックから生成されます。ローカルに同名ファイルがない場合は、先に IINA で字幕トラックを読み込んでください。

**長い動画での性能**
2 時間 45 分、2117 項目の講義録画で検証したところ、一覧のスクロールと検索に目立った遅延はありませんでした。

**他のプラットフォームには対応していますか**
対応していません。IINA 自体が macOS 専用であるため、本プラグインも macOS 専用です。

**単語単位のタイムスタンプを持つ字幕はどう表示されますか**
項目（cue）単位でまとめて表示します。単語単位の SRT も通常どおり解析され、移動先は項目の開始時刻になります。

## 対応環境

- IINA 1.5 以降（1.5.1 で検証）
- macOS（Apple Silicon / Intel）

## プライバシーと権限

プラグインは字幕ファイルを読み取るだけで、ファイルの書き込みもネットワーク通信も行いません。要求する権限は `file-system`（字幕ファイルの読み取り）と `show-osd`（プレーヤー内の通知表示）です。

## フィードバック

問題を報告する際は、IINA のバージョン、macOS のバージョン、字幕の形式、および `ウインドウ → ログビューア` に含まれる `cuejump` を含む行を添えてください。
