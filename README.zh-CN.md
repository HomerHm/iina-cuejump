# CueJump

IINA 的字幕侧边栏插件。播放时以列表形式列出当前视频的全部字幕条目，点击其中任意一条即可跳转到对应时间点。

![CueJump 侧边栏](docs/screenshot.png)

## 用途

IINA 本身只显示当前正在播放的一条字幕，既看不到上下文，也不便于定位已经播放过的内容。CueJump 在侧边栏中列出整部视频的字幕条目，并提供检索与跳转功能，主要用于以下场景：

- 回顾已播放的内容，但不记得具体时间点
- 跳转到特定章节或论点，不必按顺序播放
- 复习课程录像、访谈记录与会议回放
- 语言学习时配合 IINA 原生的按句跳转逐句查看

## 功能

| 功能 | 说明 |
|---|---|
| 字幕列表 | 在侧边栏中列出全部字幕条目，附时间码 |
| 点击跳转 | 点击任意条目，播放位置跳转至该条目的起始时间 |
| 检索 | 输入即过滤，命中文本高亮；按 `Enter` 跳转至第一条结果 |
| 播放跟随 | 当前条目高亮，列表随之滚动至可视区域中央；手动滚动后暂停跟随 1.5 秒，也可关闭该行为 |
| 字号 | 11–16 px，列表与字幕正文同步缩放 |
| 背景 | 玻璃（完全透明，显示画面）/ 磨砂（半透明）/ 不透明 |
| 界面语言 | 跟随系统语言，或手动指定中文 / English / 日本語 |

## 安装

1. 下载最新的 `iina-cuejump-x.y.z.iinaplgz`
2. 双击该文件，在 IINA 的确认对话框中点击「安装」
3. 完全退出 IINA 后重新启动（插件仅在应用启动时载入）

也可以通过 `IINA → 设置 → 插件 → 从 GitHub 安装` 填入仓库地址进行安装。

## 使用

打开带有字幕的视频，在侧边栏中选择 **CueJump** 标签页。

| 操作 | 结果 |
|---|---|
| 点击列表中的条目 | 播放位置跳转至该条目的起始时间 |
| `⌘F` | 将焦点移至检索框 |
| 输入关键词 | 实时过滤并高亮命中文本 |
| `Enter` | 跳转至第一条命中结果 |
| `Esc` | 清空检索内容 |
| `Shift + ←` / `Shift + →` | 调用 IINA 原生的上一句 / 下一句跳转 |
| `↻` | 重新读取字幕文件（修改外挂字幕后使用） |

## 字幕文件的匹配规则

按以下顺序查找：

1. 当前已加载的外挂字幕轨
2. 与视频同目录、同文件名的字幕文件，扩展名为 `.srt`、`.vtt`、`.ass` 或 `.ssa`

支持的格式为 SRT、WebVTT、ASS / SSA。ASS 与 SSA 文件中的样式覆盖码（如 `{\b1}`）在解析时会被移除。

## 设置

`IINA → 设置 → 插件 → CueJump` 提供以下选项：

- **侧边栏背景**：玻璃 / 磨砂 / 不透明
- **字号**：11–16 px
- **诊断信息**：在侧边栏中显示插件内部日志
- **语言**：跟随系统 / English / 中文 / 日本語

侧边栏中的 `A−`、`A+` 与背景按钮修改的是同一份设置，改动立即生效并保存。

## 常见问题

**侧边栏为空**
未找到字幕文件。确认视频所在目录存在同名 `.srt`（或 `.vtt` / `.ass`）文件，或在 IINA 中手动加载字幕轨，然后点击 `↻`。

**与 IINA 内置的字幕显示有何区别**
IINA 仅显示当前一条字幕。CueJump 列出全部条目，并支持检索与跳转。两者可以同时使用。

**是否会修改字幕文件**
不会。插件对字幕文件只有读取操作。

**是否支持网络视频与直播流**
列表基于本地字幕文件或已加载的字幕轨。网络视频若没有本地同名文件，需先在 IINA 中加载字幕轨。

**长视频的性能表现**
在时长 2 小时 45 分、共 2117 条字幕的课程录像上测试，列表滚动与检索均无明显延迟。

**是否支持其他平台**
不支持。IINA 仅提供 macOS 版本，本插件同样是 macOS 专属。

**逐词时间戳的字幕如何显示**
按条目（cue）聚合展示。逐词时间戳的 SRT 可正常解析，跳转精度为条目起始时间。

## 兼容性

- IINA 1.5 及以上，测试环境为 1.5.1
- macOS，支持 Apple Silicon 与 Intel

## 隐私与权限

插件对字幕文件只做读取，不修改任何文件，也不发起网络请求。申请的权限为 `file-system`（读取字幕文件）与 `show-osd`（在播放器内显示提示）。
